# Mialigo - Mario's Link Page

🚀 **Building in public** - Une page de liens personnalisée avec Next.js

## ✨ Fonctionnalités

- 🌓 **Dark/Light Mode** avec persistance localStorage
- 🔗 **Liens sociaux** : Instagram, YouTube, TikTok
- 🎨 **Animations fluides** au survol
- 📱 **Responsive** avec Tailwind CSS
- ⚡ **Next.js 16** avec App Router
- 🎯 **TypeScript** pour la sécurité du code

## 🚀 Démarrage

```bash
cd mialigo
npm install
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000)

## 📦 Technologies

- **Next.js 16.3.3**
- **React 19.2.8**
- **Tailwind CSS 4**
- **TypeScript 5**
- **Font Awesome 6.4.0**

## 🛠️ Build & Déploiement

```bash
npm run build
npm start
```

## 📝 Personnalisation

Modifiez `app/page.tsx` pour changer :

- Le nom et la bio
- Les liens sociaux
- Les icônes Font Awesome
