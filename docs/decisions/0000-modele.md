# ADR-NNNN : Titre court, sous forme de décision

- **Statut** : Proposée | Acceptée | Dépréciée | Remplacée par [ADR-XXXX](XXXX-titre.md)
- **Date** : AAAA-MM-JJ
- **Issue / PR** : #N
- **Découle de** : [ADR-XXXX](XXXX-titre.md) (ou « — »)
- **Remplace** : [ADR-XXXX](XXXX-titre.md) (ou « — »)
- **Liée à** : [ADR-XXXX](XXXX-titre.md) (facultatif)

## Contexte

Le problème à résoudre, les contraintes (techniques, sécurité, coût, délais) et ce qui a déclenché la décision. Uniquement des faits, sans la solution.

## Options envisagées

1. **Option A** : description. *Pour* : … *Contre* : …
2. **Option B** : description. *Pour* : … *Contre* : …
3. **Option C** : …

## Décision et raison

L'option retenue, et **pourquoi** elle l'emporte sur les autres. Préciser pourquoi chaque option écartée l'a été.

## Conséquences

- Ce qui devient plus simple ou plus sûr.
- Ce qui devient plus difficile, les limites acceptées, la dette créée.
- Le travail de suivi éventuel (issues à ouvrir), et les conditions qui feraient réviser cette décision.
