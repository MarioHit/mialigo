# Mario - Personal Link Page

> Building in public 🚀

A modern, responsive link-in-bio page built with Next.js 16, featuring dark/light mode toggle and smooth animations.

## ✨ Features

- 🌓 **Dark/Light Mode** with localStorage persistence
- 🔗 **Social Links**: Instagram, YouTube, TikTok
- 🎨 **Smooth Animations** on hover
- 📱 **Fully Responsive** with Tailwind CSS
- ⚡ **Next.js 16** with App Router
- 🎯 **TypeScript** for type safety
- 🚀 **Static Export** for GitHub Pages

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Tech Stack

- **Next.js** 16.3.3
- **React** 19.2.8
- **Tailwind CSS** 4
- **TypeScript** 5
- **Font Awesome** 6.4.0

## 🛠️ Build & Deploy

```bash
# Build for production (creates static export in 'out' folder)
npm run build

# Deploy to GitHub Pages via GitHub Actions (automatic on push to main)
```

## 📝 Customization

Edit `app/page.tsx` to customize:

- Name and bio
- Social media links
- Font Awesome icons

Edit `app/globals.css` to change:

- Color scheme
- Dark mode colors
- Transitions

## 🌐 Deployment

This project is configured for GitHub Pages deployment:

1. Push to `main` branch
2. GitHub Actions will automatically build and deploy
3. Your site will be live at `https://mariohit.github.io/mialigo/`
